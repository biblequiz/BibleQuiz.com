Practically, there aren't many significant changes to the rules for the 2026-2027 season. Notable changes are below:

We've adjusted the syntax of Introductory Remarks for "from consecutive verses" and "from separate verses" to specify the location and number of verses within the same remark (e.g., "From 2 separate verses of Hebrews chapter 6...").

We've clarified the Quizmaster and Judges' duties regarding misread questions. If a question is misread but deemed completable, it will now be voided and a substitute question read, unless it was being read to only one team.

We've refined the protocol for incorrect identification. If a quizzer who originally buzzed in begins to answer before being correctly identified, no foul will be assessed.

Quotation Completion questions must now start with the word "Finish," and the word "quote" must be used to signal the beginning of the Scripture.

For XP5 and Contender Divisions, all Quotation and Quotation Completion answers must come only from marked verses.

:::tip[]
If you have suggestions for future rules changes, the TBQ Rules Committee is always happy to hear your ideas! Send any questions, comments, suggestions to tbqrules@biblequiz.com.
:::
