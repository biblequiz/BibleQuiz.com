Most rules changes for the 2026-2027 season are small tweaks to help the rules be interpreted more consistently. The most notable changes are as follows:

- Added a line to the main body of the rules noting that Eligibility and Competition Structure rules can be found at [biblequiz.com](http://biblequiz.com/) and are fully enforceable
- Adjusted the "key word" definition in the glossary so that it no longer applies to questions and only applies to answers
- Clarified "What Makes an Answer Incorrect," #7 to more closely align with the rule's original intent
- Outlined the voting procedure for what to do when a contest is accepted based on Additional Scriptural Evidence
- Added a rule specifying that a coordinator serving as a coach should nominate a stand-in to handle coordinator's appeals to avoid conflict of interest
- Updated the definition of "Point of Order" in the glossary to more closely align with how it's used in-match
- Created hyperlinks throughout the document for when rules cross-reference

:::tip[]
If you have suggestions for future rules changes, the TBQ Rules Committee is always happy to hear your ideas! Send any questions, comments, suggestions to tbqrules@biblequiz.com.
:::
